# Functional golden path

Status: **not complete**. Visual productization Phase 4 targets the workbench visual contract first. Durable `sim_*` persistence is required before claiming this path.

## Checklist (pilot)

1. Employer signs in  
2. Workspace access/create  
3. Open approved evaluation (Northline DA)  
4. Edit/review blueprint  
5. Publish  
6. Invite candidate  
7. Invitation persists  
8. Candidate accepts  
9. Consent + readiness  
10. Start simulation  
11. Server timer starts once  
12. Inspect sources  
13. Filter/analyze  
14. Evidence-linked claim  
15. Refresh recovers state  
16. Preliminary conclusion  
17. Changed information released  
18. Original preserved  
19. Revise/defend  
20. Final review  
21. Submit once  
22. Employer dashboard updates  
23. Analysis states  
24–29. Report, oral defense, decision  
30–33. Work Receipt share + revoke
