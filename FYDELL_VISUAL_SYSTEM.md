# Fydell visual system

One system for public site, employer console, candidate workbench, and evidence report. They differ in density and pacing, not vocabulary.

Canonical CSS: [`src/app/globals.css`](src/app/globals.css).  
Working product contract: [`APPROVED_VISUAL_CONTRACT.md`](APPROVED_VISUAL_CONTRACT.md).

## Identity (untouchable)

- Exact chain mark
- Lowercase `fydell` wordmark
- Geist Sans + Geist Mono
- Graphite foundation

## Application grammar (Direction A)

- Full-height shell: command bar + mission rail + canvas + evidence inspector
- Hairlines and luminance steps for depth; rare soft shadow only for true overlays
- Evidence threads: selection/focus relationships in product; SVG diagrams on marketing
- Motion: 120–220ms state only; respect `prefers-reduced-motion`

## Marketing grammar

- Display type 3.4×+ body at desktop
- Product proof ≥58% of feature section width
- No tiny framed mockups; code-captured or live embeds only
- Pricing: Guided Pilot / Platform / Enterprise per [`PRICING_AND_PACKAGING.md`](PRICING_AND_PACKAGING.md)
